Choose the installation command that matches your Linux distribution:

#### Ubuntu / Debian / Mint (APT)
```bash
sudo apt update && sudo apt install -y noctalia
```

```bash
sudo dnf install -y noctalia
```

#### Arch Linux / Manjaro (Pacman)
```bash
sudo pacman -S noctalia
```

#### Alpine Linux (APK)
```bash
apk add noctalia
```

#### OpenSUSE (Zypper)
```bash
sudo zypper install noctalia
```
